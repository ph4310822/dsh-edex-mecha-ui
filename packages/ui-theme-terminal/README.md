# @danielng23/dsh-mecha-client-ui-theme-terminal

The MECHA alert-HUD token theme for the DeepSeek Harness web UI: registers the
klaxon red/orange alias-token theme (default accent `#ff3300`, warn `#ffaa00`,
error `#ff2533`, near-black card surface `#0a0b0e`) and an Appearance row
(Settings → General → Theme Color) to pick the accent.

The tokens recolor the original UI — labels, icons, borders, and background
surfaces — while the MECHA shell frame (`@danielng23/dsh-mecha-client-ui-edex`)
renders the neon panel chrome around it.
